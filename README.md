### Gofred &mdash; Go + WebAssembly UI Framework

> Build responsive web applications in pure Go.
> No JavaScript. No templates. Just Go &rarr; WASM &rarr; Browser.

```go
package main

import (
    "github.com/gofred-io/gofred/application"
    "github.com/gofred-io/gofred/foundation/text"
)

func main() {
    application.Run(text.New("Hello, gofred!"))
}
```

Composable widgets &middot; Built-in routing &middot; Responsive layouts &middot; Type-safe at compile time
